# Theme Color Management

Theme color managment is handled by the project $pec styles. Specifically these files:
- $pec/scss/color-scheme.scss
- $pec/scss/color-theme.scss

## Procedures and Actions
- Change / Add color definitions to scheme
- Change / Add color rules to theme 
- Assign rules to style defenitions
